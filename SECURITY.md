# Security Policy

## Supported Versions

Security fixes target the current stable release line and `main`.

## Reporting A Vulnerability

Report suspected vulnerabilities privately through GitHub Security Advisories:

https://github.com/victorwp288/weiss-schwarz-simulator/security/advisories/new

Please include the affected version or commit, reproduction steps, expected impact, and
any relevant environment details. Public issues are fine for ordinary bugs, but avoid
posting exploit details publicly before a fix is available.
